# SSM-HG 实验数据汇编（数据卷）

> **定位**：本文是**数据卷**——把截至 2026-09-17 全部已完成实验的**数字**集中呈现，供引用与核对。
> **配套文档**：解读、处置建议与优化方向见 **`experiments/report_conclusions.md`（结论卷）**。两文**分开存储**，本文只放数据、不下结论。
> **权威性**：本文是**汇编**，不是权威源。数字冲突时以 `experiments/results.md`（实验记录）、`experiments/decisions.md`（决议）与**产物本身**为准。
> **生成方式**：全部逐类数字由 `runs/**/results.json` 的 `test.*.per_class` 直接聚合（3 种子或 9 配对的 mean±std，ddof=1），**非转抄**；计时取自各 `config.json::timing`。
> ⚠ **凡本文数字与产物不符，以产物为准，并请回报修正。**
>
> 🔴 **重要未决问题（2026-09-17 发现）：本文全部 `micro-F1` 数值的口径存疑，引用前必读。**
> `scripts/metrics.py::micro_f1` 对输入做了 `.ravel()`，sklearn 遂按**二分类**处理，`average="micro"` 退化为
> **准确率**。已实测复核（主库 seed0 test @0.5）：记录值 **0.7795 ≡ 准确率 0.7795**，而真正的**标签对级 micro-F1 为 0.1839**；
> 极端情形——**全判负**时该函数返回约 0.93 而非 0（seed0 的 val 阈值恰落在该退化解上：`max(val_prob)=0.567 < 0.60`）。
> 波及面：`evaluate.py` 的全部上报 micro-F1、`metrics.search_global_threshold`（**阈值搜索目标**）、
> `train.py` 的 LR 调度 / 早停 / `best.pt` 选择。**尚未裁定如何处置，故本文照实保留记录值**；
> 方案与影响见结论卷 §4 待裁定 #1。
> ✅ **不受影响**（走二维接口，已逐项复算核对一致）：**macro-F1、逐类 F1、逐类 AP、mAP**。

## 0. 口径前提（读本文前必读）

1. **现行口径 = 2026-09-16 修正后的 dropout「丢弃率」语义**（`--prior-dropout 0.2` = 每图 20% 概率整幅置零）。
   修正前的全部数字（主库 micro 0.8954 / mAP 0.2980 等）**已作废**，归档 `runs/prior_dropout80/`、`runs/prior_448pool/`，**不得引用、不得与新数字混用**（`decisions.md` §26）。
2. **两组结果集并存、不可比**（§23）：① 主库 `alldata(readonly)` 与 ② 增强集 `alldata_augmentation` 各自独立完整，
   **禁止跨组比较绝对值、禁止平均或相加、禁止用 ② 的数字宣称 ① 的问题已解决**。
3. 标签序固定：`access_control, arithmetic, dos, front_running, reentrancy, time_manipulation, uncheck`（reentrancy 下标 4）。
4. 阈值只在验证集搜索；测试集**双报告**（固定 0.5 + 验证集阈值）。主指标 = **micro-F1（标签对级）**；macro-F1 为参考；
   **support ≤2 的类仅描述性呈现、不进方法间比较**（§13）。
5. 本文所有 t 值 = **同配对**差值的 t 统计量（n=9，`mean/(std/√n)`）；n=3 的臂**不报 t**（不足以判方向，见 §26.7/§27.5）。
